### 🚀 Ecosistema de Proyectos Destacados

#### ⚡ Aplicaciones Web & SaaS con FastAPI
* **[geoweather-saas](https://github.com/AngelLisandro2024/geoweather-saas):** Dashboard SaaS meteorológico full-stack. Integra geolocalización en tiempo real con **Leaflet.js**, consulta interactiva en mapa, consumo de la API de **Open-Meteo**, SQLite y sistema de autenticación de usuarios.
* **[fastapi-techradar-scraper](https://github.com/AngelLisandro2024/fastapi-techradar-scraper):** Web Scraper SaaS en tiempo real para el monitoreo de tendencias tecnológicas. Construido con **FastAPI**, **BeautifulSoup4**, Jinja2 (herencia de plantillas) e interfaz moderna con diseño *Glassmorphism*.
* **[fastapi-crypto-tracker](https://github.com/AngelLisandro2024/fastapi-crypto-tracker):** Dashboard interactivo para el seguimiento en tiempo real de criptomonedas (BTC, ETH, SOL, BNB) mediante **httpx**, Jinja2 y *polling* optimizado en JavaScript.

#### 🏥 Sistemas Institucionales & Casos de Uso Real
* **[Sistema Web Fundasalud Trujillo (Versión Final)](https://github.com/AngelLisandro2024/Sistema-Web-Institucional-Fundasalud-Trujillo-Version-Final):** Plataforma web institucional completa desarrollada con **Python (Flask)**, **SQLite** y **Bootstrap 5**. Incluye gestión integral de jornadas médicas, módulo de noticias, panel administrativo y control de usuarios.

#### 📦 Sistemas de Inventario & Control de Stock
* **[StockMaster-Hybrid](https://github.com/AngelLisandro2024/StockMaster-Hybrid-Sistema-de-Gesti-n-Multi-Dispositivo):** Sistema profesional multi-dispositivo diseñado para la sincronización local en tiempo real entre PC y móviles a través de red WiFi.
* **[Sistema Web de Inventarios v2.0 (Flask)](https://github.com/AngelLisandro2024/Sistema-inventario-minimalista-2.0-codigo):** Aplicación web modular con clasificación por categorías, cálculo dinámico de stock, buscador en tiempo real y generación de reportes en PDF. *(Versión portable independiente en [Ejecutable-sistema-inventario-minimalista-2.0](https://github.com/AngelLisandro2024/Ejecutable-sistema-inventario-minimalista-2.0))*.
* **[Sistema Control de Inventario y Préstamos (Desktop)](https://github.com/AngelLisandro2024/Sistema-control-inventario-prestamos):** Software de escritorio en **Python (Tkinter + SQLite)** con arquitectura POO, control de devoluciones por arrendatario y exportación a CSV. *(Versión ejecutable en [Ejecutable-sistema-inventario](https://github.com/AngelLisandro2024/Ejecutable-sistema-inventario))*.

#### 🔐 Gestión Administrativa & Seguridad Backend
* **[Sistema Control de Asistencia (Flask)](https://github.com/AngelLisandro2024/Sistema-control-asistencia-flask):** Solución Full-Stack para el registro de empleados, consultas avanzadas, generación de reportes y autenticación segura. *(Versión ejecutable en [Ejecutable-sistema-asistencia](https://github.com/AngelLisandro2024/Ejecutable-sistema-asistencia))*.
* **[Sistema de Autenticación con Flask y MySQL](https://github.com/AngelLisandro2024/Sistema-autenticacion-flask-mysql):** Implementación de gestión de sesiones robusta con **Flask-Login**, arquitectura modular y base de datos relacional MySQL.
