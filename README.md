### 🚀 Ecosistema de Proyectos Destacados

#### 📦 Sistemas de Inventario y Control de Stock
* **[StockMaster-Hybrid](https://github.com/AngelLisandro2024/StockMaster-Hybrid-Sistema-de-Gesti-n-Multi-Dispositivo):** Sistema profesional optimizado para sincronización local en tiempo real PC-Móvil mediante red WiFi.
* **[Sistema de Gestión de Inventario y Préstamos (Desktop)](https://github.com/AngelLisandro2024/Sistema-control-inventario-prestamos):** App de escritorio en Python (Tkinter + SQLite) con arquitectura POO y exportación a CSV. *(Versión portátil disponible en [Ejecutable-sistema-inventario](https://github.com/AngelLisandro2024/Ejecutable-sistema-inventario))*.
* **[Sistema Web de Inventarios v2.0 (Flask)](https://github.com/AngelLisandro2024/Sistema-inventario-minimalista-2.0-codigo):** App web modular con soporte para categorías, cálculo dinámico de stock y reportes en PDF. *(Versión portable disponible en [Ejecutable-sistema-inventario-minimalista-2.0](https://github.com/AngelLisandro2024/Ejecutable-sistema-inventario-minimalista-2.0))*.

#### 🕒 Control de Asistencia y Gestión Administrativa
* **[Sistema Control de Asistencia (Flask)](https://github.com/AngelLisandro2024/Sistema-control-asistencia-flask):** Solución Full-Stack para registro de empleados, gestión de roles, reportes y autenticación. *(Versión portátil disponible en [Ejecutable-sistema-asistencia](https://github.com/AngelLisandro2024/Ejecutable-sistema-asistencia))*.

#### 🔐 Seguridad y Desarrollo Web Backend
* **[Sistema de Autenticación con Flask y MySQL](https://github.com/AngelLisandro2024/Sistema-autenticacion-flask-mysql):** Implementación de gestión de sesiones con `Flask-Login` y base de datos relacional.
* **[Sistema Películas Flask-SQLAlchemy](https://github.com/AngelLisandro2024/Sistema-peliculas-flask-sqlalchemy):** Arquitectura ORM avanzada con control de acceso basado en roles (Admin/User).
